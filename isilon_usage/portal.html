🚀 원격 자동 구성 — IP만 넣으면 엣지 설치 명령 생성 + 노드 자동 등록

🔒 접속 보안 (로그인 비밀번호)

    
비밀번호를 설정하면 접속 시 읽기 전용이 되고, 우상단 로그인 후 노드 등록·원격 구성 등 변경 작업을 할 수 있습니다. 비우고 저장하면 보호가 해제됩니다.

    

      
      
      
      
      
    

    
비밀번호를 잊었다면: 포탈 서버의 데이터 폴더 portal_settings.json 에서 "op_password" 를 "" 로 바꾸고 포탈을 재시작하세요.

    

      
      
      

    

  

  

    
🔑 엣지 자기등록 토큰 (enroll token)

    
엣지 설치 시 --hq http://<이포탈>:8800 을 주면 엣지가 스스로 등록됩니다. 포탈에 로그인 비밀번호가 설정된 경우엔 엣지가 이 공유 토큰을 함께 보내야 등록됩니다(엣지 쪽 --enroll <토큰>). 비밀번호가 없으면(신뢰망) 토큰 없이도 등록됩니다. 비우고 저장하면 토큰 검사를 끕니다.

    

      
      
      
    

  

  

    
💾 백업 (포탈 설정 + 노드 목록)

    
포탈 설정·등록 노드 목록(+감사 로그·핑 이력)을 tar.gz 하나로 묶습니다. 노드 api_token·로그인 비밀번호가 포함되니 안전하게 보관하세요. (대용량 replicas/ 는 제외)

    

      
      
      
      
    

    
⏰ 자동 백업 일정 — 위 폴더에 주기적으로 저장하고, 최대 보관 수를 넘으면 오래된 것부터 지웁니다(폴더가 비어 있으면 자동 백업 끔).
