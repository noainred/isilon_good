🔌 외부 사용량 API (집계 데이터 제공)

🚀 원격 자동 구성 — IP만 넣으면 엣지 설치 명령 생성 + 노드 자동 등록

아래를 원격 엣지 서버에서 1회 복붙 실행하세요(또는 setup.sh 저장 후 bash setup.sh). 노드·토큰은 이미 포탈에 등록됨 — 엣지가 뜨면 자동 폴링.
② SSH로 원격 자동 설치 + 등록 — 위 IP에 SSH로 접속해 엣지를 설치·기동·포탈 등록까지 한 번에. (계정/비번만 더 입력하면 끝)
⚠ 포탈이 SSH로 접속해 실행합니다. 비밀번호는 저장하지 않고 1회만 씁니다(포탈 호스트에 sshpass 필요, 비번 인증 시). 신뢰망·키 인증 권장.

🏷 포탈 제목 (브랜딩)

    
상단 제목과 브라우저 탭 제목을 바꿉니다. 둘 다 비우면 기본값(“다빈치 글로벌 아이실론 관제센터 — 한국 HQ”)을 씁니다.

    

      
      
      
      
    

  

  

    
🔒 접속 보안 (로그인 비밀번호)

    
비밀번호를 설정하면 접속 시 읽기 전용이 되고, 우상단 로그인 후 노드 등록·원격 구성 등 변경 작업을 할 수 있습니다. 비우고 저장하면 보호가 해제됩니다.

    

      
      
      
      
      
    

    
비밀번호를 잊었다면: 포탈 서버의 데이터 폴더 portal_settings.json 에서 "op_password" 를 "" 로 바꾸고 포탈을 재시작하세요.

    

      
      
      

    

  

  

    
⏱ 로그인 세션 / 화면 표시

    
한 번 로그인하면 지정한 시간 동안 다시 묻지 않습니다. 업그레이드 후 첫 접속 시 변경내용 팝업은 기본으로 꺼져 있습니다.

    

      
      
      
      
    

    
유지 시간은 1~10080분(7일) 범위. 기본 30분.

  

  

    
🔐 노드 작업 비밀번호 (포탈에서 설정)

    
엣지의 작업 보호 비밀번호를 포탈에서 일괄/개별로 설정·변경·해제합니다. api_token(토큰)이 등록된 노드만 적용되며, 엣지 비밀번호를 몰라도 api_token 인증으로 푸시합니다.

    

      
      
      
      
      
    

    

  

  

    
🔑 엣지 자기등록 토큰 (enroll token)

    
엣지 설치 시 --hq http://<이포탈>:8800 을 주면 엣지가 스스로 등록됩니다. 포탈에 로그인 비밀번호가 설정된 경우엔 엣지가 이 공유 토큰을 함께 보내야 등록됩니다(엣지 쪽 --enroll <토큰>). 비밀번호가 없으면(신뢰망) 토큰 없이도 등록됩니다. 비우고 저장하면 토큰 검사를 끕니다.

    

      
      
      
    

  

  

    
💾 백업 (포탈 설정 + 노드 목록)

    
포탈 설정·등록 노드 목록(+감사 로그·핑 이력)을 tar.gz 하나로 묶습니다. 노드 api_token·로그인 비밀번호가 포함되니 안전하게 보관하세요. (대용량 replicas/ 는 제외)

    

      
      
      
      
    

    
⏰ 자동 백업 일정 — 위 폴더에 주기적으로 저장하고, 최대 보관 수를 넘으면 오래된 것부터 지웁니다(폴더가 비어 있으면 자동 백업 끔).

    

      
      
      
      
    

    

  

  

    
💬 질의응답(자연어) — 로컬 LLM

    
‘물어보기’의 숫자는 항상 규칙 엔진이 계산합니다. 로컬 LLM을 켜면 사내 GPU에서 도는 OpenAI 호환 서버(Ollama·vLLM·llama.cpp 등)로 문장만 자연스럽게 다듬습니다. 데이터는 외부로 나가지 않습니다(끄면 규칙 기반만).
