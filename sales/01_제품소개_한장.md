# Isilon 디렉터리 사용량 스캐너 + 글로벌 통합 포탈(HQ)

## 수천만 파일의 NAS를, du 메모리 폭주 없이 — 폐쇄망 다수 DC를 한 화면에서

**별도 패키지 설치 없이(표준 라이브러리만) 폐쇄망 서버에 바로 올려, 초대용량 아이실론/Dell EMC 스토리지의 디렉터리별 용량을 메모리 최소로 조사하고, 여러 데이터센터를 단일 포탈에서 통합 조망합니다.**

---

## 제품 요약

초대용량 NAS(아이실론 등, 한 폴더에 수천만 파일)에서 트리 전체에 `du`를 한 번에 돌리면 메모리가 폭주해 프로세스가 죽는 문제가 있습니다. 이 제품은 탐색→상향식 집계의 **2단계 방식**으로 디렉터리 단위로 쪼개 처리하고, 결과를 SQLite로 흘려보내 **트리 크기와 무관하게 메모리 사용량을 평탄하게** 유지합니다(테스트: 파일 5만+ 스캔에도 스캐너 RSS ≈ 24MB). 실시간 웹 대시보드로 진행·자원·드릴다운을 보여주고, 분석 리포트(콜드 데이터/소유자/확장자/용량 소진 예측 등)와 예약 스캔·알림·내보내기를 제공합니다. **글로벌 통합 포탈(HQ)**은 여러 DC를 DB 복제로 한 화면에 모아 보여주며, Python 표준 라이브러리만 쓰므로 폐쇄망에 그대로 실행됩니다.

---

## 해결하는 문제

- **du 메모리 폭주** — 수천만 파일 디렉터리에 트리 전체 `du`를 돌리면 메모리가 터져 프로세스가 죽습니다. 2단계 분할 + SQLite 스트리밍으로 회피합니다.
- **느린 NAS 스캔** — 고지연 NAS에서 기존 스레드 방식은 GIL + 단일 락 + 단일 DB 커넥션 직렬화로 약 1,000 stat/s에서 천장에 부딪힙니다(워커 8개를 줘도 1~2배에 그침).
- **흩어진 다수 DC** — 폐쇄망에 분산된 여러 데이터센터·스토리지 어레이의 용량 현황을 한눈에 볼 통합 화면이 없습니다.

---

## 핵심 가치

- **메모리 평탄** — 탐색→상향식 집계 2단계로 디렉터리 1개 분량만 메모리에 올리고 결과는 SQLite로 스트리밍. 파일 5만+ 스캔에도 스캐너 RSS ≈ 24MB(측정).
- **에이전트리스 친화** — Python 3.6+ 표준 라이브러리만 사용(웹서버·DB·자원수집 내장). 폐쇄망 서버에 패키지 설치 없이 즉시 실행, systemd 서비스 등록.
- **측정 기반 자동 튜닝(오토튜닝)** — 새 스캔 시 단일/멀티프로세스/2단 병렬을 실측해 가장 빠른 방법으로 자동 시작. 서버 사양 기반 권장 스레드 + 시범 스캔 실측 보정.
- **멀티 DC 단일 화면** — 글로벌 통합 포탈(HQ)이 여러 DC를 DB 복제로 한 화면에 조망, Cross-DC 경로 비교, 스토리지 어레이 상태(Isilon/PowerStore/Unity/PowerMax/VMAX/XtremIO/VPLEX) 통합.
- **운영에 바로 쓰는 인사이트** — 콜드 데이터(파일 나이)·소유자·확장자별 사용량, 최대 파일 Top, 용량 소진 예측, 직전 대비 변화 Top, 스캔 비교(diff).
- **경량·오픈** — MIT 라이선스, 소스 동봉. 사내 미러 '한 줄 설치', 오프라인 업그레이드(인터넷·토큰 불필요).

## 주요 기능

| 영역 | 내용 |
|------|------|
| 스캔 엔진 | 2단계(탐색→상향식 집계) `native`/`du` 백엔드, 하드링크 중복 제거(du와 일치), 메모리 최소·1회 읽기, 2단 병렬 엔진(pscan: 프로세스×스레드) + 오토튜닝 |
| 웹 대시보드 | 실시간 진행/자원(메모리·CPU·du 프로세스), 드릴다운 트리·검색, 디스크 파이차트, 워커별 현재 디렉터리, 작업 보호 비밀번호 |
| 분석 리포트 | 파일 나이(콜드 데이터)·소유자·확장자별 사용량, 최대 파일 Top, 용량 소진 예측, 직전 대비 변화 Top |
| 운영·알림 | 예약 스캔(시작+반복주기), 완료/오류 웹훅·메일 알림, CSV/JSON 내보내기, 스캔 비교(diff), 재시작/이어하기 |
| 통합 포탈(HQ) | 다수 DC를 DB 복제로 단일 화면 조망, Cross-DC 경로 비교, 스토리지 어레이 상태, Prometheus `/metrics` |
| 배포·보안 | 표준 라이브러리만(폐쇄망 즉시 실행), systemd 서비스, 한 줄 설치/오프라인 업그레이드, MIT·소스 동봉 |

## 성능 — 정직한 측정값

- **PoC 실측(멀티프로세스 pscan)**: 스레드 1→8 = 0.78배(GIL 정체), 프로세스 1→8 = 3.75배(4코어에서 거의 선형), 4워커 기준 **프로세스가 스레드의 5.48배**.
- 위 수치는 **PoC 실측값**이며, **실환경·NAS 지연에 따라 달라질 수 있습니다.** 도입 전 대상 환경에서 동봉된 측정 도구(`tools/bench_walk.py`)로 직접 확인하길 권장합니다.
- **6PB급 근본 해법(로드맵/권장)**: 아이실론 네이티브 메타데이터(SmartQuotas 어카운팅 쿼터 · FSA/InsightIQ)는 파일을 걷지 않고 클러스터 내부에서 조회하므로 가장 빠릅니다. 단, **실 클러스터 미보유로 미검증**이며 현재는 권장/로드맵으로 정직히 안내합니다.

## 왜 이 솔루션인가 (차별점)

- **폐쇄망 즉시 실행 + 에이전트리스 친화** — 표준 라이브러리만으로 동작해 별도 패키지·외부 의존성 없이 폐쇄망 서버에 그대로 올립니다(외부 CDN 없는 단일 페이지 대시보드).
- **du 메모리 폭주 회피 + 측정 기반 오토튜닝** — 메모리 평탄 스캔과, 실측으로 가장 빠른 실행 방식을 자동 선택하는 튜닝을 함께 제공합니다.
- **멀티 DC 단일 화면 + 경량·오픈(MIT, 소스 동봉)** — 분산된 다수 DC를 한 포탈로 조망하면서도, 소스를 동봉해 검증·내재화가 가능합니다.

> 비교는 사실 기준입니다. 타사 제품 비방 없이, 본 제품의 측정값과 동작 방식만 제시합니다.

## 도입 요건

- **런타임**: Python 3.6 이상 (RHEL/CentOS 7 등 구형 환경 포함). 표준 라이브러리만으로 동작.
- **OS**: Linux 서버 (아이실론 `/ifs`를 NFS/SMB로 마운트한 별도 서버에서 실행 권장).
- **네트워크**: 폐쇄망 가능. 사내 미러 한 줄 설치, 오프라인 업그레이드(포탈 릴리스 폴더에서 엣지가 당겨감 — 인터넷·토큰 불필요).
- **권한**: 마운트를 읽을 수 있는 계정. 에이전트리스 친화(대상 스토리지에 별도 에이전트 설치 불필요).
- **(선택)**: 더 정밀한 자원 지표가 필요하면 `psutil` 설치(없으면 `/proc` 자동 폴백). 운영 보안을 위해 `--mount-base`로 스캔 가능 경로 제한, 신뢰망/SSH 터널 사용 권장.
