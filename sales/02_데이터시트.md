# 데이터시트 — Isilon 디렉터리 사용량 스캐너 + 글로벌 통합 포탈(HQ)

**대상:** 대기업·제조 스토리지/인프라 운영팀 (폐쇄망 다수 DC, 아이실론/Dell EMC 보유)
**배포:** Python 3.6+ · 표준 라이브러리만 · 폐쇄망 즉시 실행 · MIT 라이선스(소스 동봉)

---

## 1. 제품 개요

초대용량 NAS(아이실론 등)에서 디렉터리별 파일 수·용량을 **메모리를 최소로** 쓰며 조사하는 도구다. 트리 전체에 `du` 를 한 번에 돌릴 때 발생하는 메모리 폭주를 회피하기 위해, 탐색→상향식 집계 2단계로 처리하고 결과를 SQLite 로 흘려보낸다(파일 5만+ 스캔에도 스캐너 RSS ≈ 24MB). 단일 엣지 노드에는 스캐너와 웹 대시보드가, 글로벌 통합 포탈(HQ)에는 여러 DC를 DB 복제로 한 화면에 모으는 집계 기능이 들어 있다.

---

## 2. 기능 표

| 영역 | 핵심 기능 |
|------|-----------|
| **스캔 엔진** | 2단계 스캔(탐색 top-down → 상향식 집계 bottom-up, 전체 디스크 1회만 읽음) · 측정 백엔드 `native`(기본)/`du` · 용량 기준 `disk`/`apparent` · 엔진 `threads`(상세 트리)/`pscan`(멀티프로세스 빠른 용량) · 오토튜닝(단일/멀티프로세스/2단 병렬을 실측해 자동 선택) · 하드링크 중복 제거(`du` 와 일치) · stat 동시 처리(N 스레드, NFS 가속) · 한 파일시스템 제한(`--one-file-system`) |
| **메모리 안전장치** | 결과를 SQLite 로 흘림(메모리에는 디렉터리 1개 분량만 상주) · 깊이 접기(DB 크기 묶고 합계는 정확) · 최대 깊이 제한 · DB 크기 가드 · 디스크 여유 자동 일시정지 · 주기적 WAL 체크포인트 |
| **분석 리포트** | 파일 나이(콜드 데이터)·소유자·확장자별 사용량 · 최대 파일 Top-N · 용량 소진 예측(추세→90%/가득 참 예상일) · 변화 Top(직전 스캔 대비) |
| **웹 대시보드** | 진행/자원 실시간 표시 · 드릴다운 트리 + 검색 · 디스크 파이차트 · 워커별 현재 디렉터리 · DB 생존 지표·하트비트(마지막 체크 + 카운트다운) · 로그/DB 디스크 여유 · 재개 누적/세션 시간 · 시스템 메모리/CPU/측정 프로세스(du) 모니터링 |
| **운영** | 실행별 DB + 관리 DB · 보존(prune) 정책 · 예약 스캔(시작 + 반복주기) · 완료/오류 웹훅·메일 알림 · CSV/JSON 내보내기 · 스캔 비교(diff) · 모든 런타임 설정 웹 편집(`settings.json` 에 저장, 재시작에도 유지) · 중단된 스캔 이어하기(resume) |
| **보안** | 작업 보호 비밀번호(보기는 자유, 작업·설정 변경에는 비밀번호) · 설정 잠금(`--lock-settings`) · 스캔 가능 경로 제한(`--mount-base`) · 폐쇄망 동작(외부 CDN 없음) |
| **글로벌 포탈(HQ)** | 여러 DC를 DB 복제로 한 화면 조망 · Cross-DC 경로 비교 · 스토리지 어레이 상태(Isilon/PowerStore/Unity/PowerMax/VMAX/XtremIO/VPLEX) |
| **통합·모니터링** | Prometheus `/metrics` 노출 · 엣지→포탈 자동 등록(enroll) · 오프라인 업그레이드(포탈 릴리스 폴더를 엣지가 당겨감) |

## 3. 시스템 요구사항 표

| 항목 | 요구사항 |
|------|----------|
| OS | 리눅스 (RHEL/CentOS 7 의 기본 Python 3.6 에서도 동작) |
| 런타임 | Python 3.6 이상, **표준 라이브러리만**(웹서버·SQLite·자원수집 내장) — 별도 패키지 설치 불필요 |
| 메모리 | 스캐너는 트리 크기와 무관하게 평탄(테스트 기준 RSS ≈ 24MB). 일반 서버 사양으로 충분 |
| 디스크 | 결과 SQLite(관리 DB + 실행별 DB) 저장 공간. DB 크기 가드·디스크 여유 자동 일시정지로 폭주 방지 |
| psutil | **선택**. 설치 시 메모리/CPU 지표가 더 정확. 없으면 자동으로 `/proc` 폴백 |
| 네트워크 | 폐쇄망에서 즉시 실행 가능(외부 인터넷 불필요). 대시보드/포탈 HTTP 포트, NFS/SMB 마운트 접근 권한 필요 |
| 권한 | 스캔 프로세스는 마운트를 읽을 수 있는 계정 권한으로 실행(NFS/SMB) |

## 4. 아키텍처

**엣지(Edge)** 는 NAS 마운트를 스캔하는 스캐너와, 진행/자원/드릴다운을 보여주는 웹 대시보드로 구성된다(systemd 서비스 `isilon-edge`). 모든 진행 상태가 SQLite 에 있어 중간에 멈춰도 데이터가 남고, 같은 `--data-dir` 로 다시 띄우면 과거 스캔과 마지막 상태를 그대로 볼 수 있다. **포탈(HQ)** 은 여러 DC의 엣지에서 DB를 복제해 받아 한 화면으로 집계·조망하고 Cross-DC 경로 비교와 스토리지 어레이 상태를 제공한다(systemd 서비스 `isilon-portal`). 권장 운용은 아이실론 `/ifs` 를 별도 리눅스 서버에 NFS/SMB 로 마운트한 뒤 그 서버에서 엣지를 띄우는 방식이다.

## 5. 배포·설치

- **폐쇄망 한 줄 설치(권장):** 엣지·포탈을 각각 사내 미러에서 `curl … | bash` **한 줄**로 내려받기·검증·설치·systemd 등록·기동까지 처리(같은 줄을 다시 실행하면 업그레이드). 엣지에 `--hq http://<HQ>:8800` 을 붙이면 포탈에 자동 등록(enroll)된다.
- **오프라인 패키지:** 압축본을 풀어 `python3 -m isilon_usage ...` 로 바로 실행(별도 설치 불필요). 사내 미러의 옛 setuptools로 굳이 설치하려면 `pip install --no-build-isolation .`.
- **오프라인 업그레이드:** 포탈의 릴리스 폴더에 새 버전을 올려 두면 엣지가 당겨가 갱신한다 — **인터넷·토큰 불필요**.

## 6. 지원 스토리지

스토리지 어레이 상태 조회를 지원하는 대상:

- **Isilon** (OneFS / PAPI)
- **Dell PowerStore** (REST)
- **Dell Unity**
- **Dell PowerMax**
- **Dell VMAX**
- **Dell XtremIO**
- **Dell VPLEX**

> 스캔 자체는 NFS/SMB 등으로 마운트된 모든 POSIX 트리에서 동작한다. 위 목록은 대시보드/포탈의 어레이 상태(용량·노드·이벤트) 표시 대상이다.

## 7. 성능 특성 (정직 표기)

- **메모리 평탄:** 결과를 SQLite 로 흘려보내 메모리에는 디렉터리 1개 분량의 엔트리만 상주한다. 트리 크기와 무관하게 사용량이 평탄하다(테스트: 파일 5만여 개 스캔에도 스캐너 RSS ≈ 24MB).
- **병렬 처리량(`pscan`) — PoC 실측값:**

  | 비교 | 결과 |
  |------|------|
  | 스레드 1→8 | **0.78배** (GIL 정체) |
  | 프로세스 1→8 | **3.75배** (4코어 거의 선형) |
  | 4워커 기준 | 프로세스가 스레드의 **5.48배** |

  > 위 수치는 **PoC 실측**이며, 실환경·NAS 지연에 따라 변동한다.

- **6PB급 근본 해법(로드맵·미검증):** 파일을 걷지 않고 클러스터 내부 메타데이터로 조회하는 **아이실론 네이티브(SmartQuotas 어카운팅 쿼터 · FSA / InsightIQ)** 가 근본적인 답이다. 실 클러스터 미보유로 **미검증 상태이며 로드맵** 항목이다.

## 8. 보안

- **작업 보호 비밀번호:** 대시보드 보기는 자유, 작업(버튼·설정 변경)에는 비밀번호를 요구.
- **설정 잠금:** `--lock-settings` 로 웹에서의 설정 변경을 잠금.
- **스캔 경로 제한:** `--mount-base` 로 웹에서 스캔 가능한 경로를 마운트 지점으로 제한(여러 번 지정 가능). 지정하지 않으면 서버 계정이 읽을 수 있는 모든 경로가 허용되므로 신뢰망이 아니면 반드시 제한.
- **포탈 등록:** 엣지→포탈 자동 등록은 토큰 기반(폐쇄망 운용 가정).
- **폐쇄망:** 외부 CDN·인터넷 의존이 없어 단절된 망에서 그대로 운용 가능. 대시보드 자체는 인증이 없으므로 내부 신뢰망에서 쓰거나 `--host 127.0.0.1` 바인딩 + SSH 터널 접근을 권장.

- **라이선스:** MIT (소스 동봉).
